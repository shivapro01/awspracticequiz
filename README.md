# AWS SAA-C03 Exam Practice Test

A self-hosted practice-exam app for the **AWS Certified Solutions Architect – Associate (SAA-C03)** exam. Questions are extracted from a PDF exam dump into structured JSON, then served through a small React quiz app with per-question checking, a review screen for wrong answers, a timer, and light/dark themes.

> **Disclaimer:** The question bank is scraped from a third-party exam-dump PDF, not an official AWS source. Answers and explanations are unverified and may contain mistakes — use this as extra practice, not as your sole source of truth.

## Features

- **1,019 questions** split into 20-question practice tests (`Practice Test 1`, `Practice Test 2`, …) for manageable study sessions.
- **Single and multiple-answer support** — questions requiring more than one correct option are handled automatically.
- **Shuffled question and option order** on every fresh attempt, so answers aren't memorized by position.
- **Per-question "Check answer"** button to reveal correctness immediately, or skip checking and see everything at the end.
- **Per-question explanations** — after checking an answer (and on the wrong-answer review screen), a panel explains why the correct option(s) are correct. Explanations live in `src/data/explanations/` and are regenerated with `npm run explanations`.
- **"Attempt later"** to mark a question as skipped and revisit it before submitting.
- **Progress sidebar** showing answered/skipped/current status for every question, with click-to-jump navigation.
- **Timer** that tracks elapsed time per test.
- **Results screen** with your score plus a full review of every question you got wrong, showing your answer next to the correct one.
- **Light/dark theme toggle**, saved across sessions.
- **Progress persistence** — in-progress answers, skipped questions, and elapsed time are saved to `localStorage` per test, so refreshing the page doesn't lose your place.
- **Restart** any test at any time to shuffle and start over.

## Tech stack

- [Vite](https://vitejs.dev/) + [React 18](https://react.dev/) for the quiz app
- [lucide-react](https://lucide.dev/) for icons
- Plain CSS (`src/main.css`) — no UI framework
- [pdfplumber](https://github.com/jsvine/pdfplumber) (Python) for one-time extraction of questions from the source PDF into JSON

## Getting started

### Prerequisites

- Node.js 18+ (tested with Node 22) and npm
- Python 3.8+ with `pdfplumber` installed, only if you need to (re)generate `questions.json` from a PDF

### Install and run

```bash
npm install
npm run dev
```

This starts the Vite dev server at `http://127.0.0.1:5173` (or the next available port). Open it in a browser to start practicing.

### Build for production

```bash
npm run build      # outputs static files to dist/
npm run preview     # serve the production build locally to sanity-check it
```

`dist/` is a fully static site — it can be hosted from any static file host (GitHub Pages, Netlify, S3 + CloudFront, or just opened locally).

## Regenerating the question bank

`src/data/questions.json` is generated from one of the PDFs in `pdfs/`. To re-run the extraction:

```bash
pip install pdfplumber
npm run extract
```

This runs `scripts/extract-questions.py`, which:

1. Opens the source PDF (`pdfs/AWS Certified Solutions Architect - Associate SAA-C03_without_discussion.pdf` by default) page by page.
2. Parses each page's question number, topic, question body, answer options, and correct answer(s) using pattern matching, stripping footer/watermark noise.
3. Includes a manual override for a page that doesn't parse cleanly (page 477).
4. Sorts all parsed questions by ID and splits them into 20-question batches (`batchSize` in the output).
5. Writes the result to `src/data/questions.json`, and prints any page numbers it couldn't parse.

To extract from a different PDF (e.g. the "with discussion" or "without answer" variant), edit `PDF_PATH` in `scripts/extract-questions.py` before running.

## Regenerating the explanations

Explanations are stored as one JSON chunk per practice test in `src/data/explanations/` (question id -> explanation text). To (re)generate them:

```bash
npm run explanations            # all tests, skipping chunks that already exist
npm run explanations -- --test 5 # just Practice Test 5
```

The script calls the `opencode` CLI (must be installed and authenticated) with 20 questions per call, validates the returned JSON covers every question, and retries failed chunks up to 3 times. Re-running only fills in missing or invalid chunks.

## Notes

- All progress is stored client-side in the browser's `localStorage`; there is no backend or account system. Clearing browser storage resets progress.
- The `pdfs/` directory contains large source files (tens of MB each) used only for the one-time extraction step — they aren't required to run the app once `questions.json` exists.
